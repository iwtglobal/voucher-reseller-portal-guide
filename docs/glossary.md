# Glossary — Voucher Reseller Portal

Educational terminology for **reseller portals** in gift card voucher distribution and electronic voucher distribution networks. Vendor labels vary.

## Core Terms

| Term | Definition |
|------|------------|
| **Reseller hierarchy** | Tree of distributors, sub-dealers, and retailers below an operator |
| **Master distributor** | Top-level reseller buying directly from the operator or brand |
| **Sub-dealer** | Mid-level reseller serving a territory of retailers |
| **Retailer / agent** | Point of sale that sells vouchers to end customers |
| **Downline** | All accounts below a given reseller in the hierarchy |
| **Float** | Prepaid balance a reseller uses to buy or sell vouchers |
| **Credit line** | Approved postpaid limit a reseller can draw against |
| **Stock transfer** | Movement of float or voucher inventory to a child account |
| **Margin cap** | Maximum markup a level may add, set by its parent or the operator |
| **Commission ledger** | Record of earnings per level for each downstream sale |
| **Territory** | Geographic or channel scope assigned to a reseller |
| **Role** | Permission set for a staff user within a reseller account |
| **Statement** | Period summary of funding, transfers, sales, and commission |
| **Bulk order** | Purchase of many vouchers delivered as a file or batch |
